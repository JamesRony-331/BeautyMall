# 用户端页面统一设计规范

## 目标与范围

为美妆服饰智能导购平台实现主页、个人中心、登录、注册四个页面。采用现有 Vue 3 + Vite + Vue Router 项目，新增 Element Plus。只修改 client/BeautyMallClient 内的前端文件，不修改后端。用户选择美妆杂志风。

## 方案与职责

已比较美妆杂志风与紧凑产品工具风，选择前者：以美妆摄影、留白和编辑式排版呈现平台定位；个人中心保持实用表单布局。
frontend-design 主导视觉；ui-ux-pro-max 检查交互、响应式和可访问性；frontend-skill 约束组件组织、样式一致性与界面克制程度。功能正确、可访问性和现有架构优先。

## 视觉规范

- 视觉主题：参考 LV、Apple、Chanel 的高端产品官网方向，采用黑白灰界面、真实美妆摄影、充足留白和清晰层级。参考其表达方式，不复制品牌标识。
- 色彩：背景 #FFFFFF；辅助背景 #F5F5F7；主文字与主按钮 #171717；次文字 #626267；边框 #DEDEE2；少量影像衬底 #EAE5DE。以上为本项目拟定色值，并非品牌官方色值。删除原粉色与梅色方案；彩色主要来自美妆摄影，状态色仅用于错误、成功和焦点等功能反馈。
- 字体：标题与正文采用系统中文无衬线字体，以字号、字重和留白建立层级；不依赖外部字体服务。
- 正文 16px，表单标签 14px；桌面主标题 48–64px，移动端 32–40px。
- 内容宽度最高 1200px；桌面边距 48px、移动端 20px；间距采用 8px 倍数。
- 表单控件圆角 4px；图片以自然矩形为主；避免重复卡片、装饰阴影和多色渐变。
- 主页采用统一摄影主视觉，文字位于低干扰区域；图片失败时保留纯色背景与完整文字。

## 页面结构

### 主页 /

顶部品牌与导航 → 美妆摄影主视觉与简短平台介绍 → 智能导购、穿搭搭配的编辑式介绍 → 账号入口 → 页脚。
品牌工作名使用“美妆灵感”，属于前端展示名称，后续可统一替换。
有效主操作为注册、登录或进入个人中心。尚无接口的导购、穿搭功能标为“即将开放”，不展示虚构产品、评价、推荐结果或统计数据。

### 登录 /login

共用品牌视觉与独立表单区域：邮箱、密码、显示密码、登录按钮、注册入口、返回首页。
支持浏览器自动填充、回车提交、字段校验、提交中禁用和明确错误提示；成功后跳转原受保护页面或个人中心。

### 注册 /register

邮箱、密码、确认密码、注册按钮和登录入口。密码要求 8–64 位，确认密码必须一致。成功后跳转登录，带入邮箱但不保存密码。无短信、验证码、忘记密码等不存在的接口入口。

### 个人中心 /profile

桌面为侧边导航加主要表单，移动端改为可换行导航。包括个人资料与账号安全。
个人资料：登录邮箱只读展示；姓名、手机号、头像地址可编辑。头像暂用首字占位；头像地址支持预览，不提供未实现的文件上传。
账号安全：旧密码、新密码、确认新密码；修改成功后清除前端会话并返回登录。退出登录仅清除前端会话。
不展示虚构收藏数、浏览记录或肤质档案。

## 接口与状态边界

- POST /sys-user/reg：application/x-www-form-urlencoded，email/password。
- POST /sys-user/login：同上；读取 data.token 和可选 data.userVO。
- PUT /sys-user/info：JSON，realName/phone/avatar；携带 Authorization Bearer token。
- PUT /sys-user/password：JSON，oldPassword/newPassword/confirmPassword。
- 请求封装统一处理 HTTP 错误和业务 code/info；401 清除会话并引导登录，403 显示后端信息。
- 开发代理和生产 API 地址通过配置提供，不把环境地址写死在页面组件内。
- 会话使用 sessionStorage；刷新后保留当前标签页登录状态，不保存密码。
- 当前后端登录未填充 userVO，且缺少读取资料接口。前端使用实际登录邮箱；其它资料初始为空，并提示“当前无法读取已有资料，仅提交本次修改的字段”。保存成功的修改仅缓存于当前会话，不能宣称已获取完整服务端资料。
- 编辑采用变更字段提交，避免把未知的服务端资料覆盖为空；不以浏览器缓存冒充服务端查询结果。

## 交互与可访问性

使用 Element Plus Form 统一校验；可见标签、错误文本、键盘焦点、至少 44px 点击目标。异步提交防止重复请求；加载和失败状态明确。页面切换更新标题；受保护路由保留安全的站内返回地址。
动效以单次轻微入场和操作状态过渡为主，支持 prefers-reduced-motion；不使用自动轮播或滚动劫持。
检查 375、768、1024、1440px 布局、无横向溢出、键盘操作和文本对比度。

## 实施与验收

组织为页面、共用布局/组件、API、会话状态、路由和设计变量，使用 Vue script setup。只产出一套统一页面。
验收包括构建、表单与请求序列验证、鉴权路由、接口错误处理及桌面/手机视觉检查。有可用后端时验证真实接口；否则明确区分模拟验证和真实联调。

## 实施时接口复核

2026-10-28 最终只读复核发现后端登录已填充 userVO，前端按实际返回对象回显资料；此前缺少 userVO 的说明保留为兼容路径，不再代表最新实现。无独立资料 GET 接口。前端未修改后端文件。旧头像地址只在用户修改该字段时校验 HTTPS，未修改的历史值不阻止其他字段保存，预览仍仅加载 HTTPS。

## 个人中心增量调整
按用户最新要求移除头像地址输入及编辑区，保留侧栏身份头像。菜单增加个人地址管理、我的收藏、我的订单；订单含全部、待付款、待发货、待评价、退款、售后。沿用黑白灰与响应式导航。缺少对应后端接口，当前实现可切换页面与状态、明确服务准备中；不改后端、不虚构业务数据。

## 商品页增量
新增 `/products` 公共页面与“全部商品”导航，黑白灰商品网格，桌面 4 列、中屏 3 列、手机 2 列。搜索栏按商品名称、分类匹配；搜索和改变每页数量重置到第一页，URL 保留 q/page/size。尚无商品接口，页面明确标注 24 件布局示例及统一示意图，不编造价格、库存或购买操作。
