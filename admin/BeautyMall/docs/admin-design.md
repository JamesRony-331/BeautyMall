# 管理端统一设计与实施规范

## 代码分析
admin/BeautyMall 当前为 Vue 3 + Vite 初始模板，已安装 Vue Router。后端 /sys-user 目前只有 reg/login/info/password 四个映射。UserMapper.selectPage 尚未在 Controller 暴露；不能把修改本人接口用作管理员编辑其他用户。全程不改后端。

## 统一设计
frontend-design 主导视觉，ui-ux-pro-max 检查交互与响应式，frontend-skill 约束组件、样式与内容一致性。保留现有黑白灰品牌，复用花瓣图标。
颜色：背景 #F5F5F7、工作区 #FFFFFF、主字/按钮 #171717、辅字 #626267、边框 #E2E2E5、焦点 #305A91。绿色/橙色仅表示状态且同时有文字说明。
系统无衬线字体，正文 14–16px，标题 28px；8px 间距尺度；6px 表单圆角；无装饰大屏、营销主视觉或虚构统计。
布局：固定 224px 侧栏 | 顶栏 72px + 页面标题 + 筛选工具栏 + 数据表 + 分页。小屏侧栏改为抽屉；表格仅在容器内横向滚动，页面不横向溢出。
固定菜单仅有商品管理、用户管理、分类管理，不由接口生成。
动效：菜单打开/关闭、按钮悬停、对话框过渡；支持减少动效设置。

## 模块
商品管理：静态样例，搜索、分类/状态筛选、分页、详情查看，明确示例标记；新增/编辑/上架等后端操作不伪装成功。
分类管理：静态样例，名称搜索、状态筛选、分页与详情；明确不保存到服务器。
用户管理：真实接口位置待用户提供。先展示真实空待接入状态与表头、筛选布局，不使用假用户或伪造请求。现有登录/修改本人接口不冒充全量用户管理能力。

## 实施计划
1. 安装 Element Plus，创建路由、统一布局、静态数据及表格组件。
2. 构建商品与分类静态页面，搜索、分页、详情使用同一组件。
3. 构建用户管理页面的查询入口和无接口状态；根据用户提供的契约接入。
4. 构建、测试搜索分页、浏览器验证三个断点与交互。记录真实接口限制。


## 用户管理接口接入更新

已接入 GET /sys-user/page（pageNum/pageSize，totalCount 为记录总数）、PUT /sys-user/{id}/info 和 PUT /sys-user/{id}/disable。使用现有登录接口获取 Bearer Token，存于当前标签页 sessionStorage；凭证失效或账号禁用时清除登录。用户模块已取代早期的待连接占位页面。无搜索或启用接口，因此不提供这两项操作。禁用需二次确认，禁止禁用本人。商品和分类保持静态，后端未修改。

## 独立认证页面

/login 和 /register 使用同一认证布局：暖灰摄影品牌区与白色表单区，手机端收起摄影。注册成功回到登录，登录进入商品管理；管理页面均有前端路由校验。注册调用现有账号接口，不会赋予管理员角色。
